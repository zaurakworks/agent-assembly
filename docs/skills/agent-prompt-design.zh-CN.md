# agent-prompt-design（中文阅读版）

英文执行合同：[`SKILL.md`](../../.cap/capabilities/skills/agent-prompt-design/SKILL.md)

> 本文件是英文 Skill 的中文阅读版，不是运行时输入，也不是第二份执行合同。两者不一致时，以英文 `SKILL.md` 为准。

## 何时使用

当任务是设计或修改 system prompt、profile prompt 或常驻 Agent 指令时使用。

## 流程

1. 恢复目标 Agent 的合同：id、目标、非目标、触发条件、输入、输出、允许的能力、禁止的能力和验收证据。
2. 按持久化层分配内容：
   - 常驻 prompt：短不变量、角色、权威顺序、安全边界和输出合同；
   - Skill：条件性、多步骤的工作流，并包含触发条件和退出条件；
   - Knowledge：带来源、版本、环境、例外和失效信号的可复用事实；
   - Task state：当前任务和决定，不能写进 prompt。
3. 让 prompt 保持朴素、可执行：写清决定、禁止越界的空间、真相源规则和验证职责。避免口号、性格填充、重复长流程、secret 和隐藏默认值。
4. 只加入选中 profile 显式声明的项目内能力。外部仓库可以启发措辞，但除非已经 vendored 到当前项目并完成声明，否则不能作为运行时依赖。
5. 明确不能声称的内容：文件存在不等于运行时生效；lock/render 证据只表示配置态；只有真实运行或客户端 probe 才能支持生效态结论。

## 完成条件

另一位审查者无需阅读聊天历史，就能判断：Agent 应做什么、不应做什么、可以使用哪些 Skill，以及如何验证声明态、配置态和生效态。
